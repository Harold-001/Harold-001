## 🔐 Security and data protection checklist I teach

A short version of what I cover in awareness sessions:

- [x] Use strong, unique passwords and a password manager
- [x] Turn on multi-factor authentication everywhere it is offered
- [x] Spot phishing emails and report them early
- [x] Keep devices patched, encrypted and protected with up-to-date anti-malware
- [x] Share personal and sensitive data only with the right people, in the right way
- [x] Back up important files and test that the backups can be restored
